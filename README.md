# Facial Recognition Project (MATLAB)

This project implements a **facial recognition system** using **MATLAB** and deep learning models.  
It was developed as part of an academic project to explore computer vision and neural network architectures.

##  Features
- Face recognition on a **custom dataset** (119 people, ~10 photos per person).
- Training and evaluation using **pre-trained deep networks**:
  - ResNet18
  - DarkNet53
  - MobileNetV2
  - NASNet-Mobile
- Combination of models using MATLAB’s **Deep Network Designer**.
- Evaluation of recognition accuracy.


## Data & Ethical Use
All participants whose photos appear in this project **gave their explicit consent** for their images to be used strictly for academic and research purposes.  
The dataset is stored and managed responsibly, respecting privacy and ethical research standards.  
No images are shared or used beyond this project’s scope.

## Requirements
- MATLAB R2023a (or newer)
- Deep Learning Toolbox
- Image Processing Toolbox
- Computer Vision Toolbox
